# BarberApp - Berber Randevu Sistemi

Modern ve kullanıcı dostu berber randevu yönetim sistemi.

## Özellikler

- 🗓️ Randevu Yönetimi
- 💇‍♂️ Hizmet Yönetimi
- 👥 Müşteri Yönetimi
- 📊 İstatistikler ve Raporlar
- 📱 Mobil Uyumlu Tasarım
- 🔔 Bildirim Sistemi
- ⚡ Gerçek Zamanlı Güncelleme

## Teknolojiler

- HTML5, CSS3, JavaScript
- Firebase (Authentication, Firestore, Storage)
- Bootstrap 5
- Font Awesome
- SweetAlert2

## Kurulum

1. Projeyi klonlayın:
   ```bash
   git clone https://github.com/kullaniciadi/barber-appointment.git
   ```

2. Proje dizinine gidin:
   ```bash
   cd barber-appointment
   ```

3. Firebase yapılandırmasını ayarlayın:
   - `js/config/firebase.js` dosyasını oluşturun
   - Firebase Console'dan aldığınız yapılandırma bilgilerini ekleyin

4. Bir web sunucusu ile projeyi çalıştırın (örn. Live Server)

## Geliştirme

Projeyi geliştirirken:

1. Yeni bir özellik eklemek için:
   ```bash
   git checkout -b feature/ozellik-adi
   ```

2. Hata düzeltmesi için:
   ```bash
   git checkout -b fix/hata-aciklamasi
   ```

3. Değişiklikleri commit edin:
   ```bash
   git add .
   git commit -m "feat: özellik açıklaması"
   ```

4. Ana branch'e merge edin:
   ```bash
   git checkout main
   git merge feature/ozellik-adi
   ```

## Commit Mesajları

Commit mesajlarında aşağıdaki prefixleri kullanın:

- `feat:` - Yeni özellik
- `fix:` - Hata düzeltmesi
- `docs:` - Dokümantasyon değişiklikleri
- `style:` - Kod formatı değişiklikleri
- `refactor:` - Kod iyileştirmeleri
- `test:` - Test değişiklikleri
- `chore:` - Genel bakım

## Katkıda Bulunma

1. Bu depoyu fork edin
2. Yeni bir branch oluşturun (`git checkout -b feature/amazing-feature`)
3. Değişikliklerinizi commit edin (`git commit -m 'feat: harika özellik eklendi'`)
4. Branch'inizi push edin (`git push origin feature/amazing-feature`)
5. Bir Pull Request oluşturun
